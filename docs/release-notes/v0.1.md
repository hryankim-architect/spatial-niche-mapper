# v0.1

**Type:** new repository (portfolio entry #9, spatial-transcriptomics axis)

## What this is

A clean-room POC of the spatial-transcriptomics analysis pattern on synthetic
data: reference-based spot deconvolution (NNLS) and spatial niche detection
(neighbourhood composition + KMeans), each scored against a known ground truth.
It pairs with `sc-tumor-annotator` (single-cell) and `hnscc-time-multimodal`
(tumor-immune microenvironment) to cover the spatial axis of the portfolio.

## Shipped in v0.1

- `synth.py`, deterministic Visium-style section: spot grid with concentric
  ground-truth niches (tumor core / immune margin / stroma), per-spot
  ground-truth cell-type proportions, single-cell reference signatures, and
  proportion-mixed + Poisson-noised spot expression.
- `deconv.py`, NNLS spot deconvolution + per-cell-type correlation and MAE.
- `niche.py`, spatial k-NN neighbourhood composition + KMeans niches + ARI.
- `pipeline.py`, CLI wiring generate → deconvolve → niche → score, with audit +
  MLflow hooks; writes a metrics artifact.
- Substrate hooks (`audit`, `tracking`, `canary`), CI (ruff + pytest +
  scope-preamble + canary + English-only), MIT license, Makefile, niche-map figure.

## Demo metrics (synthetic, seed 0; 24×24 = 576 spots, 120 genes, 6 cell types)

| Metric | Value |
|---|---|
| Deconvolution mean per-cell-type correlation | 0.918 |
| Deconvolution mean absolute error (proportions) | 0.060 |
| Niche-recovery ARI | 0.921 |

14 tests, ruff + English-only green; canary asserts deconvolution recovers the
ground-truth proportions above a floor correlation.
